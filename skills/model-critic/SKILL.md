# Model critic

1. Read the model, evidence status, experiment, active capability pack, and case policy.
2. Run only authorized `model`, `policy`, `simulation`, and `verification` tools.
3. Look for missing feedbacks, unit conflicts, negative stocks, unsupported claims, unsafe
   objectives, and nondeterministic results.
4. Produce a falsification record with defects, evidence gaps, and next actions.
5. Do not repair a defect silently, approve a model, or execute an external action.
