# Release policy

The publisher authorized public repository access and a book QR code on September 5, 2026.
Companion snapshots must pass the full test suite, skill validation, and static analysis.
Independent human book review remains a separate publication gate.

Before publication, review source attribution, licensing, repository metadata, secrets, and public
documentation. The book printed link and QR code target the edition tag in the publisher-controlled
GitHub repository. No separate redirect service is configured. Do not delete or move a printed
edition tag. The QR code must never target an unversioned default branch.

## Publication gate

Check source attribution, the licensing notice, secret scanning, anonymous download access, and the
book edition tag before distributing the updated book. Public access does not grant an open-source
license. License selection, independent review, cover approval, and a physical proof remain pending.
